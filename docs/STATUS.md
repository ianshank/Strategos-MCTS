## How to reproduce

```bash
pip install -e ".[dev,neural]"
export WANDB_MODE=disabled LANGCHAIN_TRACING_V2=false HF_HUB_OFFLINE=1 TOKENIZERS_PARALLELISM=false
python -m pytest tests/unit/ \
  --cov=src --cov-report=term-missing --cov-report=xml:coverage.xml \
  --ignore=tests/unit/test_inference_server.py \
  --ignore=tests/unit/test_rest_server.py \
  --ignore=tests/unit/test_rest_server_ext.py
```

This mirrors `.github/workflows/ci.yml` (test job installs `.[dev,neural]`, runs with
`--cov-fail-under=85`). `python-chess` and `google-adk` are **not** installed in this baseline
(nor in CI), so their modules report low/zero coverage and many chess tests skip (the 53 skips);
they are excluded from the gate via `[tool.coverage.run] omit` for the three heaviest chess files.
