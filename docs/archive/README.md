# docs/archive/

Frozen point-in-time documents, kept for historical reference and excluded from
routine maintenance. Each file carries a "Historical snapshot" banner; the
figures inside (test counts, coverage, deployment state) reflect the moment the
document was written and are **not** kept current.

- [`reports/`](reports/) — completion reports, gap analyses, setup records
- [`summaries/`](summaries/) — feature and milestone implementation summaries

For current status, always use [`docs/STATUS.md`](../STATUS.md) (test/coverage
baseline) and `docs/NEXT_STEPS_IMPLEMENTATION_PLAN_2026H2.md` (active roadmap).
New deep-research reports are written to [`docs/reports/`](../reports/), not here.
