## Literature (constraints, not new gates)

Coverage remains a floor on `src` via `tests/unit/` (Petrović, Ivanković, Fraser & Just, 2021, [arXiv:2102.11378](https://arxiv.org/abs/2102.11378); pytest-cov `fail_under`). Live LM Studio stays opt-in and out of `tests/unit/` ([Don’t mock what you don’t own](https://github.com/testdouble/contributing-tests/wiki/Don't-mock-what-you-don't-own)). Agent markdown is not the gate — `src/tools/context_docs.py` is ([AI Harness Engineering](https://arxiv.org/abs/2605.13357)). The >600 LOC god-file cut is a **local** heuristic, stricter than CWE-1080’s published 1000-LOC default; this delta did not create `settings.py` / `factories.py` / `healthcheck.py` / `constants.py` overages.
